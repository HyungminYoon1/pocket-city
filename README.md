# POCKET CITY — 작은 땅, 큰 선택

[사이트 열기](https://hyungminyoon1.github.io/pocket-city/)

5×5 땅에 주택·상점·공원·발전소·도로를 배치하는 20턴 도시 전략 게임입니다.

- 턴마다 서로 다른 건물 카드 3장 제시, 선택 후 빈 땅에 건설.
- 예산·인구·일자리·전력·환경·인접 관계를 점수에 반영.
- 땅에 포인터를 올리거나 키보드로 포커스하면 예상 점수 변화 표시.
- 건설 쉬기(+2 예산), 물과 이미 사용한 땅 건설 금지, 예산 부족 차단.
- 인구·전력 자립·환경 목표, 20턴 완료 결과, 최근 도시 점수 비교.
- 진행 중 행동 기록을 저장하고 재생해 이어하기.
- 새 도시 코드와 동일한 땅·건물 카드 순서 재현.

## 규칙과 저장 범위

초기 예산은 10이며 건설 후 기본 수입 2에 상점 수입이 추가됩니다. 주택은 인구와 전력 수요, 상점은 일자리와 수입, 공원은 환경, 발전소는 전력과 환경 부담을 만듭니다. 도로·공원·물·상점의 인접 관계와 전력·일자리 부족을 계산합니다. 건설 쉬기는 한 턴을 소모하며 예산을 2 늘립니다. 최근 완료 도시 10개와 진행 중 판 1개만 기기에 보관합니다.

## 실행과 배포

Node.js 22 이상, 런타임 외부 의존성 없음.

```sh
npm run dev -- 0
npm test
npm run check
```

개발 서버는 loopback에서 `dist/`만 제공합니다. `main`에 푸시하면 고정 SHA Actions가 시험·정적 검사 후 `dist/`를 GitHub Pages에 배포합니다. 저장소 Pages의 배포 소스는 GitHub Actions입니다.

## 기록과 개인정보

기록은 이 브라우저에만 저장하며 삭제할 수 있습니다. 계정, 분석 도구, 외부 AI API, 클라우드 저장, 전체 사용자 랭킹은 구현하지 않았습니다. CSP가 런타임 외부 연결을 막습니다. 공개 저장소에 정답·게임 규칙이 포함되므로 시험/공식 경쟁 판정 시스템이 아닙니다.
